# 戦闘表示の磨き込み（試験用・本番未反映）

## 承認範囲 / 変更前と変更後

2026-10-19、選択肢3の委任と「他の敵のアイテム獲得画面も同じ」を受けて実装。

| 対象 | 変更前 | 変更後 |
|---|---|---|
| 守る | 簡素な青い盾の図形 | 盾装備時は支給済みShield.webpを大きく斜めに構え、衝撃時に反動・散る火花・波紋。装備なしは交差した腕 |
| 戦闘メッセージ | ブレイズとエンダーマンでは視覚的に非表示 | 操作ボタン下の短文枠に攻撃・会心・防御・被弾等を表示。エンドラの既存短文も維持 |
| 敵の予告 | ！/！！/！！！ | 👊/👊！/👊！！。💪/😴は維持。プレイヤーの攻撃コマンドは装備した剣のまま |
| 撃破報酬 | 巨大な星・月桂樹と文字・アイテムが重なる | 3敵共通BattleReward。背景の光・小粒子、報酬画像、見出し、名称×1を分離 |
| 小さい画面 | 報酬画像と文字を単純縮小 | 戦場の高さに応じて縦構成→左右構成へ変更。必要時スクロール可能 |

## 影響と非対象

- 対象は現在使用されるブレイズ、エンダーマン、エンドラの3戦。演出専用BattleSpectacleと共有コンポーネントを使用。
- 勝利表示にアイテム付与・再抽選・永続化処理は持たせない。実際の付与は既存エンジンの撃破確定処理だけ。
- 戦闘計算、軽減率、HP、敵HP、消費、チケット、残り行動、報酬、必殺の採点・追加効果は変更なし。
- 以前の非表示文言に残っていた「必殺なら反撃を止める」「火球が来る時にもためている」を、実際のcounterイベントに応じた短文に修正。
- エンダーマン初回の持ち物による攻略は明かさない。水のミニゲームは従来の打ち返す方式のまま。別案の実装は保留。
- 旧プロフィール・実ユーザー・クラウド・本番は変更しない。コミット・プッシュ・デプロイ未実行。
- OSの動きを減らす設定と既存の手動設定を尊重し、静止時も盾・腕・報酬は残る。

## 確認方法

`http://127.0.0.1:5176/?battle-effects=1`

- 実データを使わないメモリ上の試験。「ブレイズ撃破直前」「エンダーマン撃破直前」「エンドラ撃破直前」で通常攻撃して報酬を確認できる。
- 「守る演出の確認」で盾あり・なしを切り替え。「盾あり・大きな火球」で実際の防御と残HPを確認できる。
- ページ再読み込みで仮戦闘は初期化。DEV以外では試験画面を読み込まない。

## 検証結果

- 全49ファイル・837テスト成功。表示専用の追加5テスト、既存の戦闘・確率・報酬・継続・保存のテストを含む。
- 型チェック・Vite/PWAビルド成功。既存の500KB超チャンク警告は継続。ビルド出力に試験ホスト・ショートカットの文言なし。
- 新規表示コンポーネント・関連の絵・試験ホストのESLint成功。差分の空白エラーなし。
- ブラウザー402×874で3敵を実エンジンの通常攻撃で撃破し、共通報酬表示を確認。ブレイズはアイテム下端345pxより見出し上端366pxが下にあり、重なりなし。最終の背景は不透明で旧敵HPも透けない。
- 320×700の低い戦場では画像と説明を左右に分離。874×402の横向きは操作ボタン横配置・短文は下段で表示。いずれも横幅のはみ出しなし。
- 盾あり・なしの防御プレビュー、装備した盾の全体表示、通常👊と大技👊！を確認。実戦で大火球を守るとHP20→17・チケット4→3・残り行動3になり、完全ガードの表現ではない。
- エンドラ勝利後の「ぼうけんへ」で試験メニューへ戻れることを確認。エンダーマンの実戦モードでは試験専用リンクを隠した。
- コンソールエラーなし。実機iPhoneとお子さんによる操作感は未確認。実データ・クラウド未操作。
