# 夜間制限・タスク・無料退出の本番反映対象

## 承認済み差分

- バトルは20:30〜翌6:30停止。採掘・クラフト・ガチャ・交換などは21:00〜翌6:30停止。親の夜間ロックOFFは両方に適用。早ね宣言の21:30締切や朝6:30のチケット付与は変えない。
- 20:30は専用の「バトルはおしまい」を表示し採掘へ戻る。「今日はおしまい」は21:00に表示。タスク実行・親チェック・親救済・早ね宣言は利用可能。
- バトルの全操作・自動入場・状態更新直前にも実時刻を確認。締切で逃走・敗北・再挑戦・必殺確定を呼ばない。保存済みHP・チケット・支払い済み行動・報酬・保留必殺を保持する。途中の演出は画面と一緒に終了し、締切後に追加消費しない。
- バトル画面は時刻境界タイマー・復帰・表示状態の変化でも検査する。画面を閉じる通知は一度のみ。21:00には採掘からタスクへ戻り、採掘画面の状態更新も直前ガードする。
- ブレイズ／エンダーマン勝利後の無料「かえる」を追加。次戦・敗北からの再挑戦は従来どおり。
- 帰宅後区分を廃止し、タスク・完了・あとで・計測記録を夜へ移行。過去履歴の判定形式と未受領権を保護。全日達成の親チェック追加チケットを1→2枚へ。1日1回、旧受領済み日は差額追加なし。

## 今回含めないもの

- 水の引っ張り式必殺の未コミット試験版。`WaterSlingGame / WaterSlingLab / waterSling*` と関連の既存スキル画面・DEV入口・説明変更は作業中のまま保持し、この反映コミットには含めない。
- 本物の子どものプロフィールを試験データで置き換える操作、在庫の補充、セーブのリセット、秘密情報・認証設定の変更は行わない。

## 検証

- 夜間判定20テスト（20:29:59.999、20:30、20:59:59.999、21:00、0:00、6:29、6:30、OFF）。バトル終了と全体終了の文言も別々に検査。
- `battleNightCutoff.test.ts` 20テストで自動入場・操作・遅延更新・再開・無料退出・保留必殺・前払い手数・各敵・タイマー後始末を確認。
- タスク移行16テスト・無料退出13テスト、その他既存テストを実行。詳細は `task-retirement-and-victory-exit.md`。
- `?task-settings=1` のメモリ試験画面で時刻と各案内を確認。試験ルートはDEV専用。証跡 `battle-night-cutoff.png`。
- 反映コミットを別フォルダへ書き出し、未コミット試験コードなしでテスト・本番ビルドを確認してからmainへ反映する。
- 既存ESLint違反は対象外のものが残る。新規の時刻・移行・報酬・コントローラコードは個別検査する。既存の500KB超チャンク警告は別件。

## 戻す場合

- コードはこの反映の差分をrevertする。利用中のプロフィール全体を古いスナップショットで上書きしない。
- 移行後のタスクを元に戻す場合は `homeRetirement` のタスク・進捗バックアップと移行後の変更を照合する。獲得済みのチケット・戦利品・受領台帳は巻き戻さない。
- 本番ドメインの問題は直前の正常なVercelデプロイへ戻せるが、移行後のセーブ形式を扱えるかを先に確認する。
