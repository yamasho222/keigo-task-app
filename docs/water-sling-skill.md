# 水の必殺：引っ張って発射

## 状態

- 公開用ブランチ：`codex/water-sling-production`。公開済みmain `01b2a30` を起点に、承認済みの水の必殺を本番へ反映する。前回公開した時間制限、無料の帰還、タスク区分移行・全日達成報酬は保持する。
- 今回のユーザー依頼によりコミット・プッシュ・本番反映を実施する。下記の練習専用ページは引き続き開発時のみ有効で、本番ビルドには含めない。
- ユーザー承認範囲：1発、毎回ランダムな泡12個、方向を自由に変更、短く引いても同じ速さ・飛距離、狙っている間は時間制限なし。泡は貫通、壁だけで反射。最初の壁＋反射後少しだけのガイド。引いている球の移動・変形と光の帯で引っ張り感を出す。

## 変更前 → 変更後

| 対象 | 変更前 | 変更後 |
|---|---|---|
| 水のミニゲーム | 6秒・次々出る10個の玉をタップ | 水の球を引っ張り、離して1発でランダム配置の泡12個を狙う |
| 採点 | 打ち返し数 / 10 | 重複を除く撃破数 / 12。6個50点、9個75点、12個100点 |
| 制限 | 時間制限 | 発射数のみ。狙う時間は無制限、1発の飛行は約5秒（初期試験版2秒から延長）。全割り時は早く終了 |
| 予測 | なし | 最初の壁までの点線＋反射後32論理px以内。次の壁で必ず打ち切り |
| 案内 | うちかえす・玉をタップ | ひっぱる・ひっぱって、はなす。開始前に指の実演 |

## 安全性・互換性

- `DragonSkillGame` の水だけを独立コンポーネントへ振り分ける。他の3種類は既存の時間制アクティビティを継続。
- 画面や球のサイズによらない320×360座標、固定速度580単位/秒。ドラッグ方向の逆向きへ発射。長さは点数や威力へ影響しない。
- 泡に接触しても方向は変わらない。壁反射の区間ごとに線分と円の衝突を計算し、遅いフレームでもすり抜けない。
- 1発で終了し、飛行中・終了後の追加発射は不可。触るだけ・短すぎるドラッグ・指操作の中断は発射数を消費しない。
- 配置はコンポーネント初期化時の独立した乱数から生成して保持。再描画・照準・飛行・画面サイズ変更で動かない。泡間に余白を確保し、上部の数表示・盤面の壁・発射位置を避ける。無限探索を避ける配置フォールバックもランダムに変化する。
- 球はドラッグ方向に最大58論理pxまで動き、盤面からはみ出さない。光の帯が伸び、球が少し変形する。離した時は発射リングから飛ぶため、ガイドと実軌道は一致する。これらは見た目だけで速度・威力を変えない。
- 1発化・ランダム配置によって得点分布は従来と異なる。全配置で100点を保証しない。泡数と既存ダメージ式を維持し、子どもの試遊で難度を確認する。
- 指が画面外へ出てもPointer Captureで操作を追跡。pointercancel / lostpointercaptureで中止。一本指のみ、盤面内はスクロール抑制。キーボードでも向きと発射を操作可能。
- 発動結果は0〜100の得点だけを既存の親へ一度通知。保存キーや必殺ID `repel`、旧 `trace` の互換処理、ダメージ計算、エンチャント・仲間・軽減効果は変更しない。
- 0点の最低保証、被ダメージの次の2回半減、1行動の消費、1チケット4行動は従来どおり。ミニゲームの照準・発射に別途チケットは不要。
- 再読み込みで保存済みの必殺を再開する場合は従来どおり0点の発動専用。選び直しや無料の再試行は不可。
- 非表示になった時は現在の点で発動する従来方式を継続。古い記録でブロックされた時や画面を閉じた時は描画・音・遅延通知を止める。
- 動きを減らす設定では背景・泡の破裂・軌跡を控えめにする。球の飛行はゲームに必要な動きとして維持。
